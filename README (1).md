## 📖 About This Repository

This repo is a structured collection of everything I've learned while building my foundation in **Python** and the core **Data Science stack**. Instead of scattering notes and scripts everywhere, I'm consolidating all my practice code, mini-projects, and experiments here — so it's easy to revisit, showcase, and build upon.

Think of this as my personal **lab notebook** 📓 for Python — every script here reflects a concept I practiced and understood, not just copy-pasted code.

## 🚀 How to Use This Repo

```bash
# Clone the repository
git clone https://github.com/<your-username>/Python-DS-Journey.git

# Navigate into the folder
cd Python-DS-Journey

# Install required libraries
pip install numpy pandas matplotlib seaborn
```

> Tkinter comes pre-installed with Python, no extra install needed 🎉
